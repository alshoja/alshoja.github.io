03 / Current Project
Work in progress Open source

Recordly

A self-hosted app for managing records and documents, with an AI assistant that can search, summarize and answer questions about your files using RAG.

  • Vue 3 and Vuetify on the frontend, NestJS on the backend, TypeScript throughout
  • Hybrid search with PgVector embeddings and optional Elasticsearch BM25
  • OCR for images and scanned PDFs, processed in the background with Redis
  • Swappable AI provider: Ollama when running locally, OpenAI in production
  • The backend checks intent and access before any data reaches the model
  • Runs entirely in Docker Compose, from PostgreSQL and Redis to the OCR worker
